### Christopher Gerrish

Sports analytics researcher building models for women's sports evaluation.

**Current projects:**

- [**NCAA Softball WAR**](https://github.com/cgerrish21/ncaa-softball-sql) (Python + SQL) — Wins Above Replacement for D1 softball. K-weighted wOBA batting, xERA pitching, Pythagenpat RPW. Team WAR predicts actual wins at R² = 0.926. 8 SQL files, multi-CTE queries, validated against a production JS pipeline at R² = 0.947.

- [**NCAAW-to-WNBA Projection**](https://github.com/cgerrish21/ncaaw-wnba-projection) (R) — Classifies 2,857 NCAA women's basketball players into three scoring archetypes from 3.3M play-by-play shots, validated against 83 WNBA players. K-means clustering recovers the same groupings. Euclidean distance comps on 10 z-scored metrics.

- [**Draft Chalkboard**](https://draftchalkboard.com) — Prospect intelligence platform covering WNBA, NWSL, PWHL, NCAA softball, and NCAA volleyball. Next.js + TypeScript, automated data pipelines via GitHub Actions.

- [**Off-Ball Defensive Valuation**](https://draftchalkboard.com/soccer/articles/off-ball-defense) (NWSL) — StatsBomb 360 freeze frame analysis finding that off-ball positioning explains 11% of goal difference variance beyond offense. Transition defense is the strongest mechanism. Published methodology; data under license.

**Languages:** Python, R, SQL, JavaScript/TypeScript

**Tools:** tidyverse, ggplot2, pandas, SQLite, Next.js, Firebase, Playwright, GitHub Actions
